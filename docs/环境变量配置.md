# 环境变量配置说明

本项目需要配置以下环境变量才能正常运行。

## 必需的环境变量

创建 `.env` 文件（复制自 `.env.example` 如果存在，或手动创建）并配置以下变量：

```env
# Supabase 配置
# Supabase 项目 URL
VITE_SUPABASE_URL=your-supabase-project-url

# Supabase 匿名密钥
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
```

## 获取 Supabase 配置

1. 登录 [Supabase Dashboard](https://app.supabase.com/)
2. 选择你的项目
3. 进入 **Settings** > **API**
4. 复制以下信息：
   - **Project URL** → `VITE_SUPABASE_URL`
   - **anon/public key** → `VITE_SUPABASE_ANON_KEY`

## 可选的环境变量

```env
# 应用环境（development/production）
VITE_APP_ENV=development

# 应用版本
VITE_APP_VERSION=2.0.1
```

## 安全注意事项

⚠️ **重要提示：**
- 永远不要将 `.env` 文件提交到版本控制系统
- `.env` 文件应该添加到 `.gitignore` 中
- 生产环境应该使用环境变量管理服务（如 Vercel、Netlify 的环境变量配置）
- `VITE_SUPABASE_ANON_KEY` 是公开的，但仍然应该保护好，避免滥用

## 部署说明

不同平台的部署方式：

### Vercel
在项目设置中添加环境变量：
1. 进入项目设置
2. 选择 **Environment Variables**
3. 添加 `VITE_SUPABASE_URL` 和 `VITE_SUPABASE_ANON_KEY`

### Netlify
在项目设置中添加环境变量：
1. 进入 **Site settings** > **Environment variables**
2. 添加所需的环境变量

### Docker
在 `docker-compose.yml` 或运行时环境变量中配置
