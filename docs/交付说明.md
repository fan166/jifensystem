# 积分制绩效管理系统交付说明

## 项目概览

本项目包含前端（React + TypeScript + Vite + Ant Design）与后端（Supabase：PostgreSQL、RLS、函数/策略）。交付包支持本地开发、生产构建及任意静态站点部署，并提供数据库迁移脚本用于初始化后端。

## 目录结构

- `dist`：前端生产构建产物
- `src`：前端源代码（组件、页面、服务、hooks 等）
- `public`：静态资源与 `index.html`
- `supabase/migrations`：数据库迁移脚本（表结构、策略、函数、权限）
- `package.json`、`vite.config.ts`、`tsconfig.json`：前端工程与构建配置
- `.env.example`：环境变量示例文件
- `scripts/deploy-local.ps1`：本地预览部署脚本（Windows PowerShell）
- `scripts/nginx.conf`：Nginx 静态站点示例配置

## 环境准备

- 前端环境变量（必须）：
  - `VITE_SUPABASE_URL`
  - `VITE_SUPABASE_ANON_KEY`
- Node.js ≥ 18，npm ≥ 9

在项目根目录新建 `.env` 文件并设置：

```
VITE_SUPABASE_URL=你的Supabase项目URL
VITE_SUPABASE_ANON_KEY=你的Supabase匿名Key
```

## 开发运行

- 安装依赖：`npm install`
- 启动开发：`npm run dev`
- 预览地址：`http://localhost:5173/`

## 生产构建与预览

- 构建：`npm run build`
- 本地预览构建产物：`npm run preview`
- 或使用脚本：`powershell -ExecutionPolicy Bypass -File scripts/deploy-local.ps1 -Port 5173`
- 部署到静态站点（Nginx/Vercel/Netlify/对象存储）时，将根路径指向 `dist` 目录，并设置 SPA 回退到 `index.html`。

## 后端部署（Supabase）

推荐使用 Supabase CLI：

1. 登录并关联项目：
   - `supabase login`
   - `supabase link --project-ref <你的ProjectRef>`
2. 推送迁移：`supabase db push`

或使用 PostgreSQL 客户端手动执行 `supabase/migrations` 下的 SQL，保持文件编号顺序。

关键迁移事项：

- 用户、部门与核心表：`000_create_users_min.sql`、`021_create_departments_min.sql`、`042_fix_missing_core_tables.sql`
- 权限与策略：`002_setup_rls_policies.sql`、`006_setup_table_permissions.sql`、`044_fix_logs_and_rls.sql`
- 奖励与绩效数据结构：`024_create_performance_reward_tables.sql`、`create_performance_evaluation_tables.sql`
- 评价批次：`027_create_evaluation_batches.sql`（如需批次功能）

## 常见问题

- 关系查询错误 `PGRST200`：说明目标外键关系未创建或缓存未识别。可在前端改为二次查询合并（项目已实现），或确保执行 `042_fix_missing_core_tables.sql` 建立 `performance_evaluations(batch_id) → evaluation_batches(id)` 外键。
- 列不存在 `42703`：检查查询语句是否通过外键嵌套获取部门名称，例如 `departments!users_department_id_fkey(name)`。
- 角色约束错误（`users_role_check`）：若数据库仍使用旧角色集合（`admin/manager/employee`），前端已在创建/更新时做兼容映射；也可执行 `032_update_user_roles.sql` 统一角色枚举。

## 验收清单

- 能在本地成功启动前端并访问 `http://localhost:5173/`
- 人员管理页面可添加用户，且邮箱与角色校验正常
- 奖励记录页面可查询/新增记录，无弹窗干扰与类型/部门显示错误
- 日常实绩评价页面能查询数据，无 `PGRST200` 或 `42703` 错误
